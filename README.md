# Libra

A Progressive Web App for cataloging your physical book library. Photograph a cover, an AI fills in the details and finds related YouTube videos; keep a wishlist; get personalized recommendations.

Progressive Web App untuk mendata koleksi buku fisik Anda. Foto sampulnya, AI mengisi detail dan menemukan video YouTube terkait; simpan wishlist; dapatkan rekomendasi yang dipersonalisasi.
